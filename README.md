# Трекер личных расходов студента

Мини-проект по дисциплине «Программирование на PHP», вариант 12.
Веб-приложение на чистом PHP (без фреймворков и базы данных): учёт доходов и расходов по категориям,
журнал операций с фильтрами, месячная сводка, остаток средств и лимиты категорий с предупреждением о превышении бюджета.

**Автор:** Оразбаев Махсуд, группа ИС 24-22 · **Преподаватель:** Рашидинов Д.Р. · **Вуз:** АТУ
**GitHub:** _вставьте ссылку на репозиторий_

## Цель
Закрепить материал лекций 1–8: типы и функции со строгой типизацией, массивы, обработка форм, валидация,
сессии, работа с JSON и файлами, безопасный вывод.

## Функции
- Добавление операции: тип (доход/расход), сумма, дата, категория, комментарий; серверная валидация.
- Журнал операций: фильтры по месяцу и категории, итоги доходов/расходов/баланса, удаление операции.
- Итоги считаются через `array_filter()` и `array_reduce()`; сумма хранится в тиынах (целое число), без ошибок округления.
- Месячная сводка: расходы по категориям, доходы, итог месяца, **остаток средств** за всё время.
- Лимиты категорий (задание повышенной сложности): бюджет на категорию, индикатор использования, предупреждение при превышении.
- Защита: POST + CSRF-токен для изменяющих действий, Post/Redirect/Get, экранирование `htmlspecialchars()`,
  блокировка и атомарная замена JSON-файла, контролируемые сообщения об ошибках.

## Требования к среде
- PHP **8.4 или новее** (расширения только стандартные; `mbstring` не нужен).
- Любой современный браузер. Платное ПО не требуется.

## Установка и запуск
```bash
git clone <ссылка на репозиторий>
cd <папка репозитория>

php scripts/seed.php            # (необязательно) демонстрационные данные: 30+ операций за 3 месяца и 3 лимита
php -S localhost:8000 -t public # запуск встроенного сервера
```
Откройте <http://localhost:8000>. Без `seed.php` приложение стартует с пустым журналом.

**Windows:** скачайте PHP 8.4+ (Thread Safe, zip) с <https://windows.php.net/download>, распакуйте, например, в `C:\php`,
добавьте папку в переменную `PATH` и проверьте `php -v`. Либо используйте XAMPP с PHP 8.4+.

## Тесты
```bash
php tests/run.php
```
Автотесты без внешних библиотек: валидация (обычные, пустые, граничные, некорректные значения), фильтры и итоги, лимиты,
CSRF, хранилище (повреждённый JSON, недоступный каталог). Данные пишутся во временный каталог.
Ручные сценарии (повторная отправка, CSRF по HTTP, метод запроса) описаны в [test-cases.md](test-cases.md).

## Структура
```
public/index.php        точка входа, обработка ошибок
public/assets/          CSS
src/                    config, storage (JSON), validation, transactions (расчёты), security (CSRF, сессия), view, controllers
templates/              PHP-шаблоны: layout, journal, add, summary, limits, error
var/data/               JSON-данные (вне public, в .gitignore)
scripts/seed.php        демонстрационные данные
tests/run.php           автотесты
test-cases.md           тестовые сценарии с ожидаемыми результатами
```

## Модель данных
`var/data/transactions.json` — список операций:
```json
{ "id": "a1b2c3d4e5f60718", "type": "expense", "amount": 150050, "date": "2026-10-18",
  "category": "Питание", "comment": "Обед", "created_at": "2026-10-18T12:00:00+05:00" }
```
`amount` — тиыны (150050 = 1 500,50 ₸). `var/data/limits.json` — `{ "Питание": 4000000 }`.

## Безопасность и данные
Персональные данные и секреты в репозитории отсутствуют; демонстрационные операции вымышленные.
Каталог `var/data` вне `public/`, файлы данных исключены через `.gitignore`.

## Ограничения и развитие
Нет учётных записей (один пользователь), нет редактирования операций, хранение в JSON подходит для небольших объёмов.
Следующие шаги: ООП, PDO и MySQL/SQLite, авторизация, редактирование, экспорт в JSON/CSV.
